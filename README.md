# 声载密语 · 语音隐写演示台

把一个 16 bit 的短消息藏进一段普通语音里，传过去之后，用密钥原样取回来。

载体不是波形，是神经网络语音编解码器（EnCodec）第 0 层的离散索引。
嵌入时保持索引直方图不变，所以嵌入前后的码字分布严格相同。

> 大创项目《声载密语——基于神经语音编解码的自适应隐写通信系统》

```
双击「启动演示台.bat」
```

等浏览器自动打开，右上角出现「模型已就绪」就可以用了（首次启动要 20—30 秒，别急着点）。

默认口令 `C0`，默认密钥 `demo-2026`。

命令行方式：

```bash
pip install -r requirements.txt
python launch.py --port 8766
```

第一次运行会自动下载 EnCodec 模型（几百 MB），下完缓存在本机，之后不再下。

## 这个项目在干什么

```
源语音 ──编码──> EnCodec 索引（每秒 75 帧，每帧 0–1023）
                      │
                      ├─ 按密钥挑出 88 个载体位
                      ├─ 保持直方图的置换嵌入（只换座位，不换书单）
                      │
                 解码回波形 ──> PCM16 WAV ──> 传出去
                                                  │
接收方：重新编码 ──> 按同一密钥取位 ──> 解交织 ──> 纠错译码 ──> 消息
```

接收端不需要原始语音，只需要算法、密钥和收到的音频。

**已知边界（写代码前先知道）**

| 能 | 不能 |
|---|---|
| 抗同一个 EnCodec 的 PCM16 往返 | 抗 MP3 / AAC 等平台转码（**未测**） |
| 抗音量降低 10 dB、16 kHz 往返 | 抗开头裁剪（裁 40 ms 就取不回） |
| 编码端直方图 L1 严格为 0 | 保证不可检测（留出集 AUC 0.578，区间下界高于 0.5） |

## 三条规矩

1. **不往仓库里塞大文件。** 模型权重、语料、批量音频一律不进 Git（`.gitignore` 已挡）。单个文件超过 100 MB 会被 GitHub 直接拒收。
2. **不改 `main`，只提 PR。** 下面有步骤，照做就行。
3. **引用数字必须带口径。** 写「交付率 95.5%」不合格，要写「E4、默认 key、382/400」。

## 怎么提交改动（三步）

第一次用，先配置：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

然后每做一件事：

```bash
# 1. 从最新的 main 开一个分支，名字写你干的事
git checkout main
git pull
git checkout -b feat/转码矩阵

# 2. 改代码，提交
git add .
git commit -m "加 MP3 三档转码脚本"
git push -u origin feat/转码矩阵

# 3. 去 GitHub 网页，点 "Compare & pull request"，写清楚改了什么，等组长合并
```

合完之后删掉分支：

```bash
git checkout main
git pull
git branch -d feat/转码矩阵
```

**分支不要活过两周。** 做完就合，合完就删。攒着不合，最后一定冲突。
