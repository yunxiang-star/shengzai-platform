# 环境搭建（Windows）

> 目标：从一台干净的电脑，到浏览器里出现「模型已就绪」。
> 预计耗时：顺利 30 分钟，不顺利 1—2 小时。**卡住是正常的，不是你笨。**

---

## 0. 你需要什么

| 项 | 要求 | 说明 |
|---|---|---|
| 系统 | Windows 10 / 11 | macOS、Linux 也能跑，本文只写 Windows |
| Python | 3.10 或以上，推荐 3.11 | 装的时候**务必勾选 "Add Python to PATH"** |
| 磁盘 | 至少 5 GB 空闲 | 依赖约 2 GB，模型缓存约 1 GB |
| 显卡 | 有 NVIDIA 显卡更好，没有也能跑 | CPU 能跑通，只是每次嵌入慢一些（几十秒） |
| 网络 | 能访问 GitHub 与 HuggingFace | 首次要下模型，之后不再下 |

检查 Python 装好没有，打开 PowerShell 输入：

```powershell
python -V
```

应该显示 `Python 3.11.x`。如果提示「不是内部或外部命令」，说明没加到 PATH，重装 Python 时勾选那一项。

---

## 1. 拿到代码

```powershell
git clone https://github.com/yunxiang-star/shengzai-platform.git
cd shengzai-platform
```

没有 git 的话，去 https://git-scm.com/download/win 装一个，一路下一步即可。

---

## 2. 建虚拟环境（强烈建议）

虚拟环境的意思是：给这个项目单独一间房，装的包不影响你电脑上其他项目。

```powershell
python -m venv .venv
.venv\Scripts\activate
```

成功的话，命令行前面会出现 `(.venv)`。

> 以后每次开新窗口干活，都要先执行 `.venv\Scripts\activate`，忘了会提示找不到包。

---

## 3. 装依赖

```powershell
pip install -r requirements.txt
```

这一步最慢，5—15 分钟，中途卡住不动是正常的（在下载 torch，约 2 GB）。

**有 NVIDIA 显卡的**，先单独装 GPU 版 torch，再装其余的，否则会用 CPU 版跑：

```powershell
pip install torch --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt
```

---

## 4. 第一次启动

```powershell
python launch.py --port 8766
```

会发生三件事，按顺序：

1. 终端开始打印日志；
2. **下载 EnCodec 模型**（几百 MB，看网速，可能几分钟）——这一步最容易以为卡死，其实在下载；
3. 浏览器自动打开页面，右上角显示「模型已就绪」。

首次加载模型要 20—30 秒。**看到「加载中」不要反复刷新**，会让它重新加载。

也可以直接双击仓库根目录的「启动演示台.bat」，效果一样。

---

## 5. 验证装好了

新开一个 PowerShell 窗口（虚拟环境要重新 activate），执行：

```powershell
python selftest.py
```

它会跑一遍嵌入—提取的完整链路，最后打印通过与否。这一步不通过，先别急着改代码。

## 6. 六种常见错误

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `ModuleNotFoundError: No module named 'fastapi'` | 依赖没装，或装到了另一个 Python 里 | 确认命令行前面有 `(.venv)`，再 `pip install -r requirements.txt` |
| `'python' 不是内部或外部命令` | Python 没加到 PATH | 重装 Python，勾选 "Add Python to PATH" |
| 端口被占用 `Address already in use` | 8766 被别的程序占了 | 换端口：`python launch.py --port 8777` |
| 模型下载卡住不动 | 网络到 HuggingFace 不稳 | 挂代理后重试；或先只跑 `python selftest.py` 看是否已缓存 |
| 画出来的直方图中文是方块 | 系统缺中文字体 | 装「思源黑体」或「微软雅黑」后重启；不影响嵌入功能 |
| 跑一次要一两分钟 | 用的是 CPU 版 torch | 正常。有 N 卡就按第 3 节装 GPU 版 |

## 7. 卡住了怎么问（这条最重要）

**不要只发一句「跑不起来」。** 按这三样发，别人一眼就能判断：

1. **你敲了什么命令**（整行，别省略）
2. **完整的报错**（从第一行 `Traceback` 到最后一行，截图也行，别只发最后一句）
3. **环境信息**：

```powershell
python -V
pip list | findstr /I "torch fastapi soundfile"
```

发到群里，或者直接开一个 issue。

**不要做的事**：

- 不要 `pip install` 一堆看着像的包来试——会把环境搞乱，越试越坏；
- 不要改 `core.py` 来「绕过」报错——它一改，嵌入结果就和论文对不上了；
- 不要删 `.venv` 又重装五次——先看清楚报错是什么。

---

## 8. 目录里哪个文件别碰

| 文件 | 为什么 |
|---|---|
| `core.py` | 嵌入/提取核心。改了会导致结果与论文数字不一致，需要组长 review 才能动 |
| `static/index.html` | 738 行单文件，多人同时改必冲突。要改先开分支，改完立刻合 |
| `assets/*.wav` | 演示用的固定样本，换了页面上的对比就失效了 |
